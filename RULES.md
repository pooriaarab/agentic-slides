# agentic-slides rules

1. Pass the real author on every edit. Do not claim a human wrote agent work.
2. Read the issue list of a failed outline. Fix every issue, then retry once.
3. Report a failed call as a failure. Never report it as success.
4. Do not point a slide at a network address for an image or a font.
5. Keep text inside its box. The tools refuse text that does not fit.
